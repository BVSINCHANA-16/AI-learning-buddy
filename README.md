# 🤖 AI Learning Buddy

An AI-powered learning assistant designed to help students learn concepts, clarify doubts, and make studying easier and more interactive.

## 🚀 Live Demo

🔗 **Try AI Learning Buddy:**
https://sinchana-ai-buddy.streamlit.app/

## 📌 About the Project

**AI Learning Buddy** is an interactive AI-based educational application that acts as a personal study companion for students.

The goal of this project is to make learning simpler and more accessible by allowing students to interact with an AI assistant for explanations, questions, and learning support.

Instead of searching through multiple resources for every doubt, students can use the Learning Buddy to get quick, student-friendly assistance in one place.

## ✨ Features

* 🤖 AI-powered learning assistance
* 💬 Interactive question-and-answer interface
* 📚 Helps students understand difficult concepts
* 🧠 Provides simplified explanations
* ⚡ Quick responses to learning-related questions
* 🎓 Designed specifically with students and learning in mind
* 🌐 Accessible through a web browser
* ☁️ Deployed using Streamlit

## ⚙️ How It Works

1. The user opens the AI Learning Buddy.
2. The user enters a question or learning-related prompt.
3. The application processes the user's input.
4. The AI generates a relevant response.
5. The response is displayed through the Streamlit interface.

## 💻 Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/BVSINCHANA-16/AI-learning-buddy.git
```

### 2. Navigate to the project folder

```bash
cd AI-learning-buddy
```

### 3. Install the required dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run app.py
```

The application will then open in your browser.

## 🔐 API Key / Secrets

The AI API key is stored securely using Streamlit Secrets and is not exposed in the source code.

For local development, configure the required API key in the appropriate secrets configuration before running the application.
